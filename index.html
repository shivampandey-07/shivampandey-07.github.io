Open source

react-native-agenda-kit

An expandable calendar, agenda and day-timeline library for React Native — published to npm under MIT.

Most calendar libraries measure row heights at runtime, which costs a frame every time the agenda scrolls. This one takes declared row heights and syncs scroll position on the UI thread with Reanimated worklets, so layout measurement never happens during a scroll — the agenda stays at 60fps on lists that used to stutter.

  • Worklet-driven scroll sync; no runtime layout measurement
  • Bundled TypeScript types and dual ESM + CJS builds
  • Zero runtime dependencies
  • Works with Expo and React Native CLI, on iOS and Android
  • TypeScript
  • Reanimated Worklets
  • ESM + CJS
  • MIT
View on npm Source on GitHub
