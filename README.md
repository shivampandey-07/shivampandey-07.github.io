# shivampandey-07.github.io

Personal portfolio — **Shivam Pandey**, Senior React Native Engineer.

**Live:** https://shivampandey-07.github.io/

Static site, no build step. Plain HTML, CSS and vanilla JS served straight from
GitHub Pages off the `main` branch.

```
index.html              # the whole page
assets/css/style.css    # styles
assets/js/main.js       # nav, scroll reveal, screenshot rails, lightbox
assets/shots/           # app screenshots (App Store / Google Play listings)
assets/icons/           # app icons
```

## Editing

Open `index.html` and edit the markup directly — the content is all inline.
To preview locally:

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

Push to `main` and GitHub Pages redeploys in about a minute.
